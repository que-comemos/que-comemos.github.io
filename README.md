# que-comemos.github.io

Páginas públicas de la app **¿Qué comemos?** (GitHub Pages):

- `/` — portada
- `/invite/?c=CÓDIGO` — invitación a la lista de la compra compartida (abre la app)
- `/privacy/` — política de privacidad
- `/app-ads.txt` — vendedor autorizado de AdMob (tiene que estar en la raíz del dominio)

Sustituye a `joseporrino.github.io/quecomemos-web/`, que se mantiene mientras haya APK con el enlace antiguo.
